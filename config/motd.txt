Welcome to briskd, an IRC server written in Erlang/OTP.

This server speaks RFC 1459/2812 and the IRCv3 extensions, including
SASL accounts, message tags, server-time, echo-message, chat history,
read markers, multiline messages, metadata, MONITOR, and WHOX.

Getting started:
  /join #lobby                               say hello

Be kind, keep it on topic, and have fun.
